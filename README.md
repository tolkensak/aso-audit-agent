# ASO Audit Agent

An AI-powered App Store Optimization audit tool built with Next.js, TypeScript, and Groq.

## Features

- 🔍 **Smart URL Parsing**: Accepts any Apple App Store URL
- 📊 **Comprehensive Audits**: Scores 7 ASO dimensions with detailed recommendations
- 🎯 **Actionable Insights**: Prioritized recommendations (Quick Wins, High-Impact, Strategic)
- 📈 **Visual Feedback**: Progress bars, scores, and before/after examples
- 💬 **Chat Interface**: Conversational UX with streaming responses

## Tech Stack

- **Framework**: Next.js 14 with App Router
- **AI**: Groq (Mixtral 8x7B)
- **Scraping**: iTunes API
- **Styling**: Tailwind CSS
- **Language**: TypeScript
